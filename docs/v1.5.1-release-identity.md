# V1.5.1 — Release identity

V1.5.1 gives the deployed app one unambiguous product version. The canonical
value is `APP_VERSION` in `lib/app-version.ts`; package metadata is checked
against it in tests.

This version is distinct from two compatibility/runtime values:

- the rules profile (`merciless-baseline-v1`), which pins game meaning;
- the table revision (`TABLE REVISION N` in the UI), which increments after
  accepted actions and is not an application release.

The release identity is available to document metadata and privacy-safe issue
diagnostics. Deployments may optionally set
`NEXT_PUBLIC_OPEN_SHED_BUILD_ID` to a short, non-secret commit or CI slug. The
value is rejected unless it is at most 64 ASCII letters, numbers, dots,
underscores, or hyphens. Never put a token, URL, account identifier, or other
secret in this public variable.
