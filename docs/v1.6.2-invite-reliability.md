# V1.6.2 — Invite Reliability and Opt-in Player Lobby

V1.6.2 improves friend-invite recovery and adds an explicitly opt-in way for willing players to find one another without publishing a global signed-in-user directory.

## Authorization recovery

- Valid private invite codes remain in the Sites-managed Sign in with ChatGPT return path.
- Invite pages explain that ChatGPT authorization shares basic identity, not conversations or files.
- When mobile authorization is denied before Open Shed receives the request, players are guided to retry in Safari or Chrome, use a personal ChatGPT account, or ask a managed-workspace administrator.
- Open Shed cannot intercept the provider-owned `/callback` denial page, so the product does not claim that an upstream denial was an in-game join failure.

## Opt-in player lobby

- Visibility is off by default and requires a separate, explicit 2–24 character public alias. Account and table names are never prefilled.
- Only a fresh, opted-in player can receive invitations. Their opaque locator expires after 45 seconds without a lobby heartbeat; no profile ID, table code, game ID, or exact timestamp crosses the directory API.
- Only a fresh sole host of an open waiting table can browse the directory or send an invitation. Seekers receive their own state and incoming invitations, not the wider directory.
- Incoming invitations show only the host's separately entered public alias. Players can accept, decline, or decline and durably block the sender; hosts can hide and durably block a directory entry.
- Acceptance atomically claims a seat, rotates both table aliases, sets an event visibility floor, clears lobby presence, unlists the table, and permanently changes table communication to public-safe quick phrases only.

## Safety and reliability

- Public aliases reject hidden controls, links, contact details, phone-like strings, and social handles.
- Send, response, block, recipient, and sender-recipient pair quotas limit probing and harassment.
- Durable request hashes make lost-response retries body-bound; invitations expire after five minutes and terminal rows are deleted after the replay horizon.
- Every create and join path clears opted-in presence in the same receipt-guarded D1 batch.
- Chat messages from before a player's join time are excluded from that player's feed and cursor space.
- `OPEN_SHED_LOBBY_PRESENCE_ENABLED` is an independent exact-`true` kill switch.

## Deferred

- First-party lobby-alias moderation reports remain a follow-up. The launch includes durable bilateral blocking and the global feature kill switch; the existing table-level report system remains available after joining.
- Guest sessions that bypass Sign in with ChatGPT are a separate security and identity project, not part of this release.
