# V1.1 — Game Night Loop

V1.1 turns the rules-complete table into a dependable game-night journey:

1. Share a real invitation URL.
2. Join the intended room after sign-in.
3. Understand readiness and the next legal action.
4. Recover from ordinary mobile/network interruptions without duplicate moves.
5. Finish with a useful result and start a same-room rematch.

## Player-facing scope

- `?join=CODE` is the non-member invitation route. `?game=ID` remains the member-only re-entry route.
- Lobby copy is player-facing, with one primary invite action, visible ready progress, and a reason whenever Start is disabled.
- The table presents one contextual Turn Coach instruction, an accessible in-game rules guide, and urgent actions in a mobile-safe dock.
- Connection state is explicit: Live, Syncing, Reconnecting, or Offline. At most one in-flight command is persisted and retried with the same command ID.
- Presence is separate from rules state. Hosts may remove another player only after the server verifies that the player exceeded the inactive grace period.
- Completion shows the winner, reason, remaining-player summary, and actions for rematch or returning to the games list.
- Rematch keeps the room and active roster, clears all round state, returns everyone to an unready lobby, and starts only after readiness is confirmed again.

## Release boundaries

V1.1 does not add chat, voice, video, matchmaking, spectators, rankings, alternate decks/rule profiles, rich audio/animation systems, or complete private replays.

## Acceptance journey

The release demo must complete this chain in two isolated browser identities:

`share link → sign in → join → ready → start → legal play → disconnect → recover without a duplicate command → complete → rematch`

The same journey must remain usable at 320px, with touch and keyboard input, reduced motion, visible focus, no root overflow, and no private opponent or deck data in public payloads.

## Reliability targets

- Valid invitation opens reach the intended lobby at least 85% of the time.
- Remote state appears within three seconds at p95 under the polling transport.
- Accepted command responses complete within one second at p95.
- Simulated lost-response retries execute a command exactly once.
- No critical or serious accessibility findings ship.

These funnel targets are provisional until privacy-safe production telemetry establishes a baseline.
