# V1.6.1 — Rules Clarity and Quality

V1.6.1 makes the complete Merciless baseline understandable from every product state without changing the game engine or the versioned rules profile.

## Player-visible release

- One typed, immutable rules registry powers both the signed-out rules page and the in-game guide.
- The in-game guide now covers setup, normal turns, draw stacking, Mercy, 0/7 hand movement, UNO, both win conditions, Draw-pile recycling, every core Action card, the complete 168-card inventory, and Open Shed's deterministic online rulings.
- Results label the rematch history **Round wins**. The optional card-points method to 1,000 remains disabled and is clearly separate.
- The app release is `1.6.1`; table revisions and the Merciless baseline rules profile remain separate compatibility concepts.

## Accessibility gate

- The rules guide is a labelled modal document with an early Close action, focus trap, Escape handling, exact trigger restoration, inert background, and locked background scrolling.
- Its table of contents uses real links, moves keyboard focus to each destination, and remains usable without motion.
- The deck manifest is a semantic description list; headings follow the page/dialog hierarchy; decorative card art is hidden from assistive technology.
- Controls are at least 44 CSS pixels. The dialog and signed-out rulebook must reflow at 320 CSS pixels and 200% zoom without document-level horizontal scrolling.

## Stability and performance gate

- Recoverable route and global error boundaries expose no stack traces, digests, table IDs, or private state.
- Polling remains single-flight, bounded by reconnect backoff, and cleans up controllers and browser listeners.
- LiveKit stays in a dedicated lazy client chunk. CI enforces budgets for eager JavaScript, the largest eager chunk, total JavaScript, LiveKit, and CSS after every production build.
- V1.7 may add optional official points-to-1,000 scoring as a separate, selectable rules mode; it is not part of this release.
