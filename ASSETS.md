| Paths | Provenance and purpose |
| --- | --- |
| `public/og.png` | Open Shed promotional artwork created for project sharing and link previews. |
| `public/assets/cards/charcoal-pressed-paper.webp` | Project-generated texture used by the original card presentation. |
| `docs/design/option-1-card-reference.webp` | Generated Open Shed design concept used as an internal visual reference. |
| `docs/design/option-1-card-comparison-*.jpg` | Project-created QA composites comparing the concept with the implementation. |
